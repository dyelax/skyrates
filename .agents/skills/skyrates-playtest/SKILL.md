---
name: skyrates-playtest
description: Answer questions from a Skyrates play session and record reproducible bugs or confirmed clarity problems in the captain’s designated playtest tracker.
---

Use the player’s question and the supplied game context to identify the screen, port, voyage, or lesson involved. Check the current rules in the Skyrates repository. The game model, objective definitions, handbook, battle model, and scene code are the source of truth for their respective features.

For a question, answer in player terms. Name the control, destination, condition, or tradeoff that helps the captain act. If the UI gives conflicting instructions, or the player has no way to discover the answer in context, record the specific clarity improvement.

For a suspected bug, compare the observed result with the intended rule. Reproduce it in a disposable game save when practical. Keep observations distinct from hypotheses. If a critical reproduction detail is missing, ask one focused question.

When the playtest thread has an owner-designated private tracker, check for an existing item about the same behavior. Add evidence to that item or create one actionable checkbox. Include the affected screen, minimal reproduction, expected behavior and a way to verify a fix. A question fully answered by existing cues needs a direct answer. A concrete gap deserves a tracked item.

If this chat has no configured tracker, give the player a copyable TODO and ask where to file it. Confirm what was actually recorded and link the private item when available.
